# 跨阈护盾·恐惧破壁者 （`hero-cross-threshold`）

> 来源：《千面英雄》(约瑟夫·坎贝尔) · 用「一盏神灯」蒸馏的技能包

## 这是什么
决心已下却被“怕被拒怕搞砸”卡在门口？帮你真的踏过那道门槛。

## 触发场景（说出这些，技能即被加载）
- 想入行但怕被拒
- 面对大佬不敢开口
- 一直卡在行动第一步

## 怎么用
在对话里描述上述场景，WorkBuddy 会按 SKILL.md 的 description 匹配并加载本技能，引导你走对应方法论。
技能自带“边界”提示（哪些情况不要用），避免硬套模板。
